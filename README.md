# Nocturne — 眠りと瞑想

ブラウザで開くだけで動く、睡眠と瞑想のための静的アプリ。
ビルド不要・依存ゼロ・通信ゼロ。GitHub Pages にそのまま置ける。

## 機能

| 画面 | 内容 |
|---|---|
| **呼吸** | 4-7-8 / ボックス呼吸 / 共鳴呼吸（5.5秒） / 生理的ため息。息の深さを縦軸にとった波形が流れ、その上をドットが進む。ドットは吸うほど大きくなり、上の「吸いきり」線までの距離がそのまま「あとどれだけ吸うか」になる。フェーズの変わり目は合成音と振動で知らせる（NSDRの読み上げ中は自動で控えめになる） |
| **サウンド** | ホワイト・ピンク・ブラウンノイズ、波、雨、バイノーラルビートを重ねられるミキサー。すべて Web Audio による合成。スリープタイマー（終了1分前からフェードアウト） |
| **NSDR** | 10分ボディスキャン / 20分ヨガニドラ風。端末の音声合成で読み上げ（オフ可） |
| **併走** | 呼吸・NSDR・サウンドは独立して動き、画面を移っても止まらない。3つ同時に走らせられる。走っているものはタブに印が出る |
| **睡眠ログ** | 就床・入眠潜時・中途覚醒・起床・離床を記録し、睡眠効率を集計。直近7日のグラフと、睡眠制限法の考え方にもとづく今夜の床上時間の提案。CSV書き出し |
| **リズム** | 起床時刻と目標睡眠時間から、光・カフェイン・仮眠・運動・入浴・ウィンドダウンの時刻を逆算 |

そのほか：減光モード、全停止ボタン、セッション中の画面ロック抑止（Wake Lock）、
PWA としてホーム画面に追加可能。

各機能をなぜその形にしたか、根拠がどこまで強いかは **[docs/EVIDENCE.md](docs/EVIDENCE.md)** にまとめてある。

## 公開する

### 方法1：ブランチから配信（最も簡単）

リポジトリの **Settings → Pages** で Source を *Deploy from a branch*、
ブランチを `main`、フォルダを `/ (root)` にする。数十秒で
`https://<ユーザー名>.github.io/<リポジトリ名>/` が開く。

`.nojekyll` を置いてあるので、Jekyll の処理は走らない。

### 方法2：Actions で配信

`.github/workflows/pages.yml` を同梱してある。**Settings → Pages** の Source を
*GitHub Actions* にすると、`main` への push で自動的に公開される。

## ローカルで動かす

ES モジュールを使っているため `file://` では開けない。HTTP で配信する。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## テスト

睡眠指標と呼吸パターンの計算は DOM に依存しない純関数に切り出してあり、Node だけで実行できる。

```sh
node tests/sleep-math.test.mjs
node tests/breath-math.test.mjs
```

## 構成

```
index.html              画面の骨組みとタブ
styles/app.css          トークンとレイアウト（暗色前提）
js/main.js              ハッシュルーティング、減光モード、全停止
js/audio.js             Web Audio エンジン（ノイズ生成・タイマー・合図音・ダッキング）
js/breath-math.js       呼吸パターンの時間計算（純関数・テスト対象）
js/breath-graph.js      呼吸の波形グラフ（スクロール描画・ドットの拡縮）
js/breath-session.js    呼吸セッション（画面から独立して動く）
js/nsdr-session.js      NSDRセッション（画面から独立して動く・読み上げ）
js/sleep-math.js        睡眠効率と床上時間の提案（純関数・テスト対象）
js/chart.js             睡眠効率のバーチャート（インライン SVG）
js/store.js             localStorage ラッパ
js/util.js              DOM と時刻のヘルパ
js/views/*.js           画面ごとの実装
docs/EVIDENCE.md        設計根拠と出典
tests/                  ユニットテスト
```

## データの扱い

睡眠ログと設定は端末の `localStorage` にのみ保存される。サーバーへの送信も、
アカウントも、外部リソースの読み込みもない。ブラウザのサイトデータを消せば
記録も消えるので、残したい場合は CSV で書き出しておくこと。

## 注意

体調を管理・診断するアプリではない。眠れない状態が数週間続く、日中の眠気が強い、
いびきや呼吸の乱れを指摘された、といった場合は医療機関に相談すること。
睡眠制限法は日中の眠気を一時的に強めるため、運転や機械操作を伴う場合は特に慎重に。
